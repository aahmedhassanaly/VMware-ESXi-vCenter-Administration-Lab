# Documentation

This folder contains the task-by-task implementation notes for the VMware ESXi and vCenter lab.

## Task Workflow

For each task:

1. Read the objective and requirements.
2. Complete the implementation in the lab.
3. Capture verification evidence.
4. Troubleshoot using **Problem → Evidence → Hypothesis → Test → Fix → Verify**.
5. Update the document with actual results and lessons learned.
6. Mark the task complete in the root README only after verification.

Task files are added in order. Future task documents are planning placeholders until their lab work begins and is verified.
